# DataEase v2 仪表板功能功能明细与集成建议 PRD (精细化版)

## 1. 业务背景
DataEase v2 的仪表板（Dashboard）模块与数据大屏（dvCanvas）模块在路由和设计理念上有所区别。仪表板模块（顶级路由 `/dashboard`）侧重于**企业级报表、高度交互和结构化布局**。本项目旨在学习其具体的按钮功能逻辑，以便在 AI Agent 驱动的 BI 项目中进行功能集成。

## 2. 仪表板编辑器 (Editor) 功能明细

### 2.1 顶部工具栏 (DbToolbar) 按钮明细
工具栏是仪表板的操作中枢，以下是基于 `DbToolbar.vue` 源码提取的按钮及其具体逻辑：

| 区域 | 功能名称 | 对应按钮/图标 | 详细操作逻辑 |
| :--- | :--- | :--- | :--- |
| **左侧** | **退出/返回** | `icon_left_outlined` | 调用 `backToMain`，检查 `styleChangeTimes`，若有未保存修改则弹出确认框。支持返回主工作台或嵌入环境。 |
| | **名称编辑** | `dvInfo.name` | 双击触发 `editCanvasName`，通过 `Teleport` 将输入框挂载到名称位置。验证长度为 1-64 字符。 |
| | **撤销 (Undo)** | `icon_undo_outlined` | 从 `snapshotStore` 获取上一个快照，并触发 `matrix-canvasInit` 重新初始化画布。 |
| | **重做 (Redo)** | `icon_redo_outlined` | 从快照历史中前进到下一个状态。 |
| **中间** | **视图/图表** | `dvView` | 弹出 `UserViewGroup` 列表。图表分类包括：指标类、折线/柱状、饼图/环形、表格类。点击触发 `handleNew`。 |
| | **查询控件** | `dvFilter` | 弹出 `QueryGroup`。核心组件为 `VQuery`，支持单选/多选下拉、日期区间、数值范围等。 |
| | **富文本** | `dvText` | 快速插入富文本编辑器组件。 |
| | **媒体/网页** | `dvMedia` | 支持图片、视频及网页 Iframe 内嵌。 |
| | **Tab/容器** | `dvTab` | 插入 `DeTabs` 组件。允许在同一区域通过 Tab 标签切换不同的视图组件。 |
| | **组件复用** | `icon_copy_filled` | 触发 `multiplexingCanvasOpen`。允许跨仪表板搜索并拷贝现有的图表及其完整配置。 |
| **右侧** | **外部参数** | `icon_params_setting` | 配置 `OuterParamsSet`。定义 URL 参数映射，支持外部系统通过参数过滤仪表板数据。 |
| | **批量操作** | `dvBatch` | 切换 `batchOptStatus`。进入批量模式后，支持组件的多选、**批量复制**、**批量删除**。 |
| | **仪表板配置** | `dvDashboard` | 全局属性设置：画布尺寸自适应模式、背景颜色/透明度、背景图片、网格线显示。 |
| | **隐藏列表** | `dvHidden` | 触发 `openHiddenList`。管理在当前布局中隐藏的组件，支持从列表中恢复显示。 |
| | **移动端设置** | `icon_phone_outlined` | 触发 `mobileConfig` 事件。允许用户为移动端配置一套独立的组件堆叠顺序和样式。 |
| | **预览** | `Dropdown` | 提供两个选项：1. **全屏预览** (当前页)；2. **新页预览** (跳转至 `/preview` 路由)。 |
| | **保存** | `Save` 按钮 | 调用 `saveCanvasWithCheck`。同步当前 `componentData` 和 `canvasViewInfo` 到后端快照表。 |
| | **发布** | `Publish` 按钮 | 修改发布状态。支持：**发布**、**取消发布**、**恢复到发布版本**（回滚未保存的修改）。 |

### 2.2 画布交互 (Interactions)
*   **双击编辑图表**：双击图表区域直接进入 `ViewEditor`（视图编辑器），进行维度和指标的修改。
*   **拖拽排版**：基于网格系统（Matrix）的组件排版，支持组件自动吸附和重叠检查。
*   **右键菜单**：支持组件的层级调整、复制、隐藏、以及**设置联动 (Linkage)**。

## 3. 技术实现架构 (重点参考)

### 3.1 核心数据结构 (Pinia: `dvMain`)
*   `componentData`: 一个包含所有组件实例信息的数组（ID, 类型, 坐标, 尺寸）。
*   `canvasViewInfo`: 一个以组件 ID 为键的对象，存储图表的具体配置（如：数据集 ID、SQL 逻辑、图表样式细节）。
*   `snapshotStore`: 管理操作历史，实现撤销/重做功能。

### 3.2 仪表板与大屏的技术差异
*   **布局逻辑**：大屏（dvCanvas）侧重绝对定位，而仪表板（Dashboard）侧重**网格自适应 (Matrix Layout)**，更适合在不同分辨率的浏览器上展示。
*   **主题方案**：仪表板固定使用 `light`（明亮）和 `dark`（暗黑）两套系统，组件样式更加标准化。

## 4. 建议集成到本项目的“黄金功能”

### 4.1 必选：组件化“复用”逻辑 (Multiplexing)
*   **集成价值**：AI 生成图表可能不完美。集成“复用”功能后，用户可以快速从 AI 之前生成成功的报表中“借用”图表，极大提升生产力。

### 4.2 必选：网格自适应排版 (Matrix Adaptive)
*   **集成价值**：AI 输出坐标时，容易出现重叠。集成 DataEase 的网格自适应逻辑，可以让 AI 只输出“大概位置”，由画布自动完成对齐。

### 4.3 核心：联动设置 (Smart Linkage)
*   **集成价值**：作为 AI Agent 项目，用户会期望“点击地图，柱状图联动”。集成 DataEase 的联动设置逻辑（字段映射），可以让 Agent 辅助完成复杂的配置过程。

### 4.4 增强：隐藏列表 (Hidden List)
*   **集成价值**：AI 一次性生成的组件可能过多。隐藏列表可以作为一个“垃圾桶”或“暂存区”，让用户在微调布局时更灵活。
